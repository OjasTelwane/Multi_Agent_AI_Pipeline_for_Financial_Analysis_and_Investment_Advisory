## 💡 Why This Project Matters

In modern finance, the "Information Gap" has been replaced by the **"Synthesis Gap."** There is too much data and not enough time to analyze it. This project solves that by moving beyond simple chatbots to a **coordinated workforce of AI specialists.**

### 1. Beyond Single-Prompt AI
Standard LLMs often hallucinate financial figures or miss market context. This system uses **Multi-Agent Delegation**, where agents peer-review each other’s work, significantly increasing the reliability of the financial data.

### 2. Specialized Cognitive Labor
By separating "Research" from "Strategy," the system avoids cognitive bias. The **Technical Analyst** doesn't care about news sentiment; the **Sentiment Agent** doesn't care about RSI levels. Their collision in the final report creates a balanced, 360-degree view.

### 3. Scalable Alpha Generation
What takes a human analyst 4 hours (reading SEC filings, checking news, analyzing charts), this pipeline completes in **under 120 seconds**, allowing for the analysis of entire sectors in the time it usually takes to research one stock.

## 🏗️ The Agentic Workflow

This repository demonstrates a **Hierarchical Architecture**, mimicking a real-world hedge fund structure:

* **The Researcher (The Scout):** Deep-dives into real-time web data and news.
* **The Technical Analyst (The Quant):** Processes price data and volume trends.
* **The Investment Strategist (The Partner):** Cross-references the Scout and the Quant to build the final strategy.
* **The Manager (The Filter):** Validates that all data is consistent and the output is professional.
